# antd 组件清单与 Paper Ink 开发优先级

记录日期：2026-10-12。

组件范围依据 [Ant Design 官方组件目录](https://ant.design/components/overview/)，本次查询页面版本为 6.6.5。核心目录共 73 个条目，包含组件、配置入口和工具项；Input.TextArea、Checkbox.Group 等子组件不单独计数。另列官网展示的 6 个 Pro Components 扩展组件，它们不属于核心 antd 包。

## 评分原则

推荐指数表示 Paper Ink 当前的开发优先级，综合通用性、使用频率、实现成本和已有基础，不代表组件自身的质量或长期价值。

| 指数 | 含义 |
| --- | --- |
| 5/5 | 优先做，构成基础可用版本 |
| 4/5 | 明确值得做，基础稳定后推进 |
| 3/5 | 后续补充，最好有真实场景推动 |
| 2/5 | 需求明确时再做 |
| 1/5 | 目前不建议投入 |

成本按做好常用 API 和交互估计，不按完整复制 antd 计算。标注“已有”的组件以完善现有实现为主；本表不是全部实现的承诺。独立设计的组件单独列出，不计入 antd 核心目录。

保持既定方向：通用 React + TypeScript 组件库，默认黑白主色、保留语义色，常规 API 接近 antd，主题结构独立设计，支持 npm 与 CLI 源码双分发，完全开源，从简单组件逐步推进。

## 近期建议批次

以下是原始讨论建议，已有组件已完成常用 API 子集，网页将其归入“完善已有组件”。5/5 代表优先级高，仍可能因依赖和实现成本排在后续批次。

| 批次 | 组件 | 目标 |
| --- | --- | --- |
| 第一批 | Checkbox、Radio、Switch、Tag、Alert、Spin、Empty | 补齐基本选择、状态与反馈 |
| 第二批 | Tabs、Tooltip、Message、Divider、Card | 形成完整页面组合能力 |
| 第三批 | Select、Dropdown、Popover、Popconfirm、Drawer | 建设并复用锚点弹层和复杂交互 |

第一批先实现 Checkbox、Radio、Switch，并把文档站“实际场景”升级为完整设置页。Tooltip 起步时建设共享锚点弹层能力，后续供 Select、Dropdown、Popover、Popconfirm 复用。

Form、Table、DatePicker 值得做，但建议分别立项设计，避免首期就承担它们的完整复杂度。

## 每个组件的交付要求

- 明确本期支持的 API、默认值、事件行为，以及与 antd 的差异。
- 支持适用的 className、style、原生属性、ref 和受控/非受控模式。
- 沿用语义主题变量，新增组件变量只表达明确的覆盖用途。
- 同步 npm 导出、独立 CSS、CLI registry 与依赖清单。
- 提供紧凑的文档、真实交互演示和必要的行为验证。
