# 文档站搜索与主题实验室

文档站工具独立于组件库 API。新增搜索和实验室控件不增加组件清单条目，也不改变组件实现状态。

## 组件与文档搜索

- `apps/website/src/data/documentation.ts` 是导航和搜索共用的目录，记录路由、名称、分类、用途和别名。新增文档时在这里维护导航与检索信息。
- 侧栏顶部的搜索框实时筛选目录，支持中文、英文、常用别名、子组件和 Hook 名称；没有匹配项的分类隐藏，清空恢复完整目录。切换文档后清空筛选，手机导航同时关闭。
- 顶部搜索在首页与文档页均可用。点击按钮或按 Cmd K / Ctrl K 打开搜索弹窗，方向键选择、Enter 跳转、Esc 关闭并恢复焦点；输入法组合输入期间不处理跳转。
- 结果按名称与路由、别名、描述依次匹配；多个搜索词需要全部匹配，同分保持原目录顺序。结果展示名称、分类和一句用途。
- 子组件和 Hook 定位到已有父级文档，如 Password → Input、RangePicker → DatePicker、useUpload → Upload。不索引未实现的子组件。
- 使用本地静态数据检索，无搜索服务、网络索引或全文引擎。首版不提供文档正文检索和拼音检索。

## 主题实验室

实验室使用真实 `ConfigProvider` 和组件。设置面板与文档站导航保持白纸浓墨，只有预览区域消费实验主题。

- 主色提供墨黑、信息蓝和草木绿预设；ColorPicker 和 HEX 输入可编辑颜色。高级区域可逐项编辑 Tone 的实心、悬停、按下、前景、淡色和边框颜色。
- 单独修改一个颜色仅覆盖该项。“生成配套颜色”是明确点击的配置工具，不改变组件库的主题解析与派生规则。
- 支持成功、警告、错误、信息色，主/次/禁用文字，页面/容器/浮层/淡色背景，边框、圆角、字号和三档控件高度。默认主色与语义色沿用现有主题，间距固定为 4 / 8 / 16。
- Button、Input、Modal 只暴露当前已有的圆角和内边距覆盖。可关闭组件覆盖，恢复跟随全局变量；不提供虚构的组件 Token。
- 输入与选择预览包含 Input、Select、Checkbox、Switch、DatePicker 以及正常、错误和禁用状态。展示与反馈包含 Button、Tag、Alert、Card、Progress。
- 实际场景包含可提交的小表单、Modal、Dropdown 和 Tooltip，能检查浮层背景、文字及组件覆盖是否继承同一实验主题。
- 关键前景与背景组合显示实际对比度及可读性提示。首版颜色输入限定为不透明六位 HEX，无效输入不会写入主题；这不是任意 CSS 背景或透明叠层的完整无障碍审核。

## 配置保存与恢复

- 自动保存当前实验配置到本机 localStorage；刷新和重新进入实验室时恢复。只恢复已知字段及有效范围，损坏数据回退到默认值。
- 可复制传给 ConfigProvider 的 JSON 配置，也可下载 JSON 文件。恢复默认同时恢复颜色、尺寸和组件覆盖。
- 存储与剪贴板失败提供反馈，不阻断主题修改；实验配置不会写入组件库默认值，也不会影响其他文档页。
- 暗色预设、配置导入和完整主题编辑器留待后续需求；当前可手动试验现有颜色变量。

## 验证范围

- 搜索目录与现有页面一致，中英文、别名、子组件、Hook 和排序均有单元检查。
- 浏览器验证侧栏筛选、快捷键、键盘导航、输入法保护、焦点恢复及手机端布局。
- 配色和恢复模型检查对比度、明确生成操作、非法配置与尺寸范围。
- 浏览器验证真实组件样式、选择与输入、Form 提交、浮层继承、配置复制与下载、持久化与失败回退，并检查桌面/手机页面。

## 快速开始与页签标识

快速开始提供 npm、cnpm、Yarn、pnpm 四种安装命令切换。当前未发布的版本使用本地 tgz 安装，发布后的 registry 命令折叠展示；仓库开发仍使用既定 pnpm workspace。

文档页签标题从共享目录生成，采用“中文名 英文名 - Paper Ink”格式；中文页面保留“页面名 - Paper Ink”，首页展示品牌和组件库定位，未知路由展示未找到状态。favicon 使用本地黑白 SVG 墨滴与 π 标记，静态入口使用相对路径，支持子目录部署。

导航品牌标记与浏览器 favicon 直接复用同一份 `apps/website/public/favicon.svg`，导航显示为 28px，旁边保留 paper ink 字标；不再使用另一套斜体 pi· 图形。

## 首页与组件画廊

首页保留品牌标题和墨水成形入场，主入口为“查看演示”和“开始使用”。右侧为明确标注的“组件预览”，按按钮、输入与选择、选中与状态三组展示真实组件，包括主要/默认/禁用按钮、输入框、选择器、复选框、开关与标签。控件可直接试用，不包含工作室或发布准备等业务场景；完整场景交互放在组件画廊。

`#/showcase` 是独立组件画廊，与首页一样不显示完整侧栏，保留品牌、搜索和顶部文档入口。画廊使用默认黑白主题和少量语义色，以操作、输入、项目列表、浮层反馈和工作室表单五组场景展示真实组件交互。各区域提供对应文档链接，不重复 API 表格或代码编辑器。现有“实际场景”页继续作为文档中的组合案例。

首页与画廊在手机端采用单列布局；本地模拟任务和保存均明确标注，不连接业务后台。入场与组件过渡无回弹，减少动态效果设置下保持静态展示。
