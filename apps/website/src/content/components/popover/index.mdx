# Popover 气泡卡片

可交互浮层，支持 12 种位置、hover / focus / click、受控显示、延迟和容器定位。

## API

## 支持边界

<DocBoundary>

定位和主题继承与 Tooltip 保持一致。默认挂到 body；在 Modal/Drawer 内自动挂到对应 dialog，保证浮层内交互可以获取焦点；getPopupContainer 可覆盖。首期不支持箭头、contextMenu、fresh 和语义样式函数。className/style 用于浮层，兼容 overlayClassName/overlayStyle。

默认 180ms 淡入淡出与 4px 位移；Dropdown、Popconfirm 复用该动画。关闭期间内容保留但不可交互，destroyOnHidden 在退出结束后生效。所有新增动效遵循 prefers-reduced-motion；减少动态效果时直接切换。

</DocBoundary>
