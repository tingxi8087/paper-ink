# Drawer 抽屉

从边缘打开详情面板，支持四个方向、嵌套焦点栈、滚动锁和焦点恢复。

## 支持边界

<DocBoundary>

支持原生面板属性。首期不支持 `push`、`loading`、`rootStyle`、语义样式、自定义 `closeIcon`、`autoFocus` 和 ref。

四个方向均支持 260ms 滑入/滑出，遮罩同步淡入/淡出。`afterOpenChange` 在动画结束后调用，关闭结束后再销毁内容、恢复焦点和滚动；遵循系统减少动态效果设置。`getContainer={false}` 保留在当前 DOM 但仍固定于视口。

</DocBoundary>
