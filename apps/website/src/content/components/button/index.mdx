## 与 antd 的兼容范围

常规属性名称和用途参考 Ant Design Button，保留 type、size、shape、htmlType、loading 等使用习惯。支持 color（default / primary / danger）、六种 variant、对象形式的 classNames / styles（root / icon / content）和 autoInsertSpace。color + variant 成对提供时覆盖 type / danger；仅提供一项时按兼容回退规则解析，建议成对使用。

加载时使用原生 disabled 阻止重复提交；链接禁用或加载时移除 href 并设置 aria-disabled。图标由使用者提供，不捆绑图标库。iconPlacement 优先于旧的 iconPosition；loading 支持自定义 icon。两汉字间距仅处理纯字符串的普通按钮内容，不处理 React 元素内部文本，不改变可访问名称。默认字号与三档高度参考 antd，但不承诺像素级一致。暂不支持预设色名称和函数形式的语义样式配置。

ConfigProvider 的主题变量结构独立设计，且当前会渲染一个 display: contents 的作用域元素。暂不支持 antd 的 algorithm、prefixCls、全局 componentSize 或完整 ButtonRef。颜色派生和暗色预设尚未实现，当前覆盖只修改明确提供的变量，关联状态色需要一并配置。
