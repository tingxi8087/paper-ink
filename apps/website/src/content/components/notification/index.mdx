## 支持边界

<DocBoundary>

提供 Hook、静态 API 和 App.useApp().notification。静态调用使用默认主题；Hook 配置在初次渲染时确定。按 key 更新会取消正在退出的通知；关闭回调在 180ms 退出后执行，淘汰与卸载直接清理，减少动态效果时直接移除。

支持四角固定定位。自定义容器仍按视口定位。不提供折叠堆叠、拖拽、进度条或悬停暂停计时；需要暂停或任务控制时使用 duration=0。

</DocBoundary>
