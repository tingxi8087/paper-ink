## 支持边界

<DocBoundary>

不沿用 antd Table 控制模型。不内置请求、实际排序、过滤、编辑引擎，也不二次切页。字段仅顶层 key；固定列需数字宽度。省略只对实际溢出提示，复杂内容显式给 Tooltip。支持受控详情展开、数据单元格纵向/横向合并及单行表头横向合并。纵向合并组的详情统一置于组末，收起卸载详情。合并不跨选择列、展开列或左右固定区域。树形、多级表头、多列排序、拖拽和虚拟滚动暂未提供。选择 Hook 使用业务行内 _checked，跨页保留请自行维护 keys。示例接口均为浏览器内本地模拟。Hook 面向浏览器，不要求 SSR。

</DocBoundary>
