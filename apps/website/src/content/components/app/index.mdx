## 使用边界

ConfigProvider 应在 App 外层。确认回调支持 Promise，执行期间显示 loading；拒绝时保持弹窗并允许重试。每个 App 的消息和弹窗独立，卸载会清理并结束等待。

本期提供 message、modal，未实现 notification。App 不替代 ConfigProvider，不包含路由或全局状态管理。组件外调用仍使用 message 静态入口，其主题为默认主题。

```tsx
import { App } from 'paper-ink/app';
import 'paper-ink/app/style.css';
```

CLI：`paper-ink add app`。

App 的 modal 保留退出动画，动画结束后再移除确认框、完成 handle 并调用 afterClose；message 沿用消息动效。所有新增动效遵循 prefers-reduced-motion；减少动态效果时直接切换。
