## RangePicker API

通过 `DatePicker.RangePicker` 使用，或从日期入口导入 `RangePicker`。默认按先后排序，排序后重新校验禁用规则；禁用端点已有值不会被交换覆盖。

## 支持边界

<DocBoundary>

- 支持日/月/年、日期时间、范围、严格输入、快捷项、中文/英文、键盘操作和 Form 自动绑定。
- `showTime` 仅与 `picker="date"` 组合。分钟精度同时设置 `format="YYYY-MM-DD HH:mm"` 和 `showTime={{ format: 'HH:mm' }}`。
- 纯日期选择即提交，日期时间默认点确定。关闭取消未提交草稿；Escape 还原文本。无效输入保留并标记错误，不会自动变成另一日期。
- `minDate/maxDate` 按选择粒度限制日期；当天的时分秒边界使用 `disabledTime`。时间步长与输入同样校验，既有值不自动舍入。
- Dayjs 采用本地时间，业务自行决定接口格式、时区和范围端点是否包含；不自动给结束日期加 23:59:59。
- 范围在宽屏显示双月，窄屏使用单月。范围作为一个 Form 字段管理。
- 暂不提供周、季度、多日期、Calendar、时间范围、12 小时制、时区模式、任意日期格渲染、受控面板模式或 SSR 保证。

</DocBoundary>
