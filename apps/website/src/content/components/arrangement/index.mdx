# 布局 Stack / Inline / SimpleGrid

Stack 竖排，Inline 横排，SimpleGrid 多列排列。每个容器只渲染一个 div；普通子元素无需包装。布局属于独立设计的 API。

## 使用边界

<DocBoundary>

需要跨列时使用 SimpleGrid.Item，或直接在子元素上设置 style.gridColumn。自动列数采用 CSS Grid 的 auto-fit，根据容器可用宽度决定列数；容器比最小宽度更窄时退到一列。

columns 字符串直接使用 CSS grid-template-columns 语法，如 `240px minmax(0, 1fr)`。自定义列模板和通过 style 覆盖列定义时，跨列范围由使用者负责。

不提供断点对象、跨行或指定起始位置的快捷属性；可以通过 className、style 和媒体查询扩展。默认不添加背景、内边距或固定高度。

</DocBoundary>
