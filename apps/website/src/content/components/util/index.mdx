# Util 工具类型

提取公开组件的属性与 ref 类型，类型工具在编译后消失。

## 使用示例

```tsx
import { Input, Select } from 'paper-ink';
import type { GetProps, GetProp, GetRef } from 'paper-ink';

type InputProps = GetProps<typeof Input>;
type InputHandle = GetRef<typeof Input>;
type Option = GetProp<typeof Select, 'options'>[number];
type OnChange = GetProp<InputProps, 'onChange'>;
type Result = GetProp<{ load?: () => Promise<string> }, 'load', 'Return'>;
```

<DocNote>回调属性中的 undefined / null 会被 GetProp 去除，适合直接声明事件处理函数。</DocNote>

## 支持边界

<DocBoundary>

仅提供类型，无运行时函数或 CSS。泛型组件优先传入已实例化的组件或公开 props 类型；不恢复已被擦除的泛型。GetProps 不接收原生标签名，原生属性使用 React.ComponentProps；GetRef 支持原生标签名。

</DocBoundary>
