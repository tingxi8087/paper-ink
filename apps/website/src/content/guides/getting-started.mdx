# 快速开始

在已有的 React 18+ 项目中使用 Paper Ink。React 和 ReactDOM 由项目提供；源码方式还需要 TypeScript。

## 选择安装方式

<QuickStart />

## 按需引入

组件包的 JS 支持 tree shaking。也可以使用组件子路径，并只引入对应的样式：

```tsx
import { Button } from 'paper-ink/button';
import 'paper-ink/button/style.css';
```

完整样式和按需样式选择一种即可。组件自带默认主题，普通使用无需包裹 ConfigProvider。
