# 快速开始

## 安装与引入

当前为本地开发版本，尚未发布到 npm。下面展示未来的包使用方式；现在可以先构建并打包，然后在项目中安装生成的 tgz。

```bash
pnpm build
pnpm --dir packages/paper-ink pack
# 在消费项目安装生成的 paper-ink-0.1.0.tgz
```

```tsx
import { Button } from 'paper-ink';
import 'paper-ink/style.css';

export default function App() {
  return <Button type="primary">保存</Button>;
}
```

## CLI 安装源码

也可以把 Button 安装到业务项目，直接拥有并修改源码。CLI 与 npm 包来自同一份实现。

当前 CLI 尚未发布到 npm。从 Paper Ink 仓库操作你的 React 18+ TypeScript 项目：

```bash
pnpm build:registry
pnpm cli init --cwd /absolute/path/to/your-app
pnpm cli add button input modal --cwd /absolute/path/to/your-app --dry-run
pnpm cli add button input modal --cwd /absolute/path/to/your-app
```

默认安装到 src/components/paper-ink，包含所选组件、共享主题、ConfigProvider 和 CSS；Modal 会同时安装 Button，且目标项目需要已安装与 React 版本一致的 react-dom。从目标项目的 src/App.tsx 引用：

```tsx
import { Button, ConfigProvider } from './components/paper-ink';
import './components/paper-ink/style.css';
```

init 的 --path 可以选择目录，CLI 不修改已有路径别名或应用入口。已有别名可自行使用。

重复安装会保留已有组件和本地修改；无归属的冲突文件会中止安装。只有显式传入 --overwrite 才替换。--dry-run 不写文件、不安装依赖。把 paper-ink.json、paper-ink.lock.json 和安装的源码一起提交。

源码形式和 npm 形式的主题 Context 独立，单个组件树中应一致选择一种方式。当前没有自动合并上游更新的功能。

## 按组件引入

JS 支持 tree shaking；样式可以选择完整入口或组件入口。Button 自带默认主题变量，不强制要求包裹 ConfigProvider。

```tsx
import { Button } from 'paper-ink/button';
import 'paper-ink/button/style.css';
```

## 主题配置

ConfigProvider 接收嵌套的语义变量，未覆盖的字段继承上层配置。inherit 为 false 时从内置默认主题开始。

```tsx
import { Button, ConfigProvider } from 'paper-ink';

<ConfigProvider theme={{
  token: {
    color: { primary: {
      solid: '#1677ff', solidHover: '#4096ff',
      solidActive: '#0958d9', onSolid: '#ffffff'
    } },
    radius: { control: 8 }
  },
  components: { Button: { paddingInline: 20 } }
}}>
  <Button type="primary">保存</Button>
</ConfigProvider>
```

当前采用显式覆盖，不自动派生颜色。主题结构与 antd 不同，这是有意设计的兼容差异。

## 在线编辑示例

组件页里的每个示例都能编辑 JSX 并实时编译预览，支持函数组件和 Hooks。编辑器是站内示例执行环境，不支持任意 npm 包安装或模块 import；修改后的代码不会自动写入项目文件。语法或渲染错误会显示在示例下方，修正或重置即可恢复。

## 开发命令

```bash
pnpm install
pnpm dev           # 官网与实时组件预览
pnpm typecheck
pnpm test
pnpm build         # 组件库和静态官网
pnpm test:browser
pnpm check:size
pnpm check:package
PLAYWRIGHT_CHANNEL=chrome pnpm check:cli
```
