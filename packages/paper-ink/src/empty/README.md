# Empty

Supports image ReactNode/URL, imageStyle legacy alias, description (false/null hides), children footer, className/style/ref/native div attributes and object classNames/styles for root/image/description/footer. Provides PRESENTED_IMAGE_SIMPLE and PRESENTED_IMAGE_DEFAULT as original monochrome SVGs. Defaults to 暂无数据.

No semantic style functions or ConfigProvider.renderEmpty integration yet.
