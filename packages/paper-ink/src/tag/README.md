# Tag

Supports color (semantic success/processing/error/warning/info/primary/default, eleven preset colors, or CSS color), variant filled/solid/outlined, bordered legacy alias, icon, closable/closeIcon, disabled, onClose, native span props/ref. Preventing onClose removes no content. closeIcon false/null hides the close action. CheckableTag is controlled with checked/onChange, native button props/ref and icon. Styling and accessible keyboard close actions are included.

No CheckableTagGroup, href, semantic styles/classNames or close animation yet. Custom colors in filled mode use a neutral background; solid mode uses the supplied color with white text, which callers should check for readability.
